# Simple Banking Application

A simple console-based Banking Application developed in Java. The application allows users to create and manage bank accounts and perform basic banking operations such as deposits, withdrawals, transfers, and transaction management.

## Features

- Create and manage bank accounts
- Deposit money
- Withdraw money
- Transfer money between accounts
- Check account balance
- Record banking transactions
- Display account information
- Console-based user interaction

## Tech Stack

- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- ArrayList
- Exception Handling
- Console Input/Output

## Project Structure

- `Main.java` – Entry point of the application and user interaction
- `BankAccount.java` – Represents a bank account and its details
- `AccountOperations.java` – Handles banking operations
- `Transaction.java` – Represents transaction information
- `services.java` – Provides supporting banking services

## Application Flow

**User → Main Menu → Account Operations → Deposit / Withdraw / Transfer → Transaction Processing → Update Account Balance → Display Results**

## Main Banking Operations

### Deposit
Allows the user to deposit money into a bank account and update the account balance.

### Withdraw
Allows the user to withdraw money after checking the available account balance.

### Transfer
Allows money to be transferred from one account to another.

### Transactions
Banking activities are recorded as transactions for tracking purposes.

### Account Management
The application maintains account information and provides the current balance and related details.
